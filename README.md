# HexDiff

Edytor i porównywarka plików binarnych (ECU, EEPROM, firmware) – **https://hexdiff.neocities.org/**

## Pobierz dla Windows

Najnowszy instalator jest w zakładce **[Releases](https://github.com/HexDiff-byDar0/HexDiff/releases/latest)**.

- Instalacja tylko dla bieżącego użytkownika, bez uprawnień administratora.
- Zainstalowany program aktualizuje się sam.
- Przy ostrzeżeniu Windows SmartScreen kliknij „Więcej informacji” → „Uruchom mimo to”.
